What this is

The problem

Program status is self-reported, and self-reports are optimistic. The costly one is the watermelon: an update labelled green whose own text describes a blocked vendor, a missed date or a team that just lost half its engineers. A lead reading forty of these a week will miss some, and the miss shows up later as a surprise escalation.

What Jev is

Jev is TypeSafe AI’s System One model. It doesn’t write prose — it returns typed decisions with calibrated probabilities: choice (pick one option), noul (probability of yes) and score (a point on an ordered scale). Many questions are answered in one parallel call, typically in 100–300 ms, billed on input tokens only.

Why Jev fits this job

Judging an update is a fast, repeated, typed decision — not a writing task. One call returns all six answers for roughly $0.00003, so it is cheap enough to run on every update from every team. Output tokens are free, so the sixth question costs about the same as the first. And because each answer is a probability, the escalation cut-off becomes a policy decision you can tune, rather than a model’s opinion you have to accept.

What code does, and what Jev does

Jev’s own docs say it is unreliable with dates and arithmetic, so it never sees a maths problem here. Code parses the claimed label and turns “3 weeks behind” into days, then floors health at yellow past 7 days and red past 21. Jev judges the language. When code overrules Jev, the page says so — see the note above the seed strip.

What was measured

50 synthetic updates whose labels were written from scenario facts before the text existed, split into 30 for tuning and 20 held out. Jev plus the code rules caught 11 of 13 watermelons with 0 false alarms in 34 honest updates. Trusting the author’s label catches none, by construction. The same 50 through Groq-hosted gpt-oss models caught 3 — at 2–3× the latency and 1.6–3.6× the cost.

What this does not prove

Fifty examples, all synthetic, all written by one person: a sanity check, not a benchmark. The escalation threshold was tuned on the first 30, and recall on the held-out 20 fell from 91% to 71%. The LLM comparison used one untuned prompt at low reasoning effort, so a better prompt would close part of that gap. All of it is in the repo, including the misses.

Code reads the numbers (the claimed label, “3 weeks late” → days); Jev reads the language. Escalation thresholds are policy, set from a labelled eval, not model output.
